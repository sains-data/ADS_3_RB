Distribusi sampling digunakan untuk memahami kestabilan nilai dan menilai kemampuan mahasiswa menguasai mata kuliah Analisis Data Statistika (ADS). Dengan melihat pola distribusi rata‑rata sampel, dapat diketahui apakah nilai mahasiswa stabil, homogen, dan mencerminkan pemahaman yang konsisten terhadap materi.

# Variabel
- Nilai akhir mahasiswa kelas RA, RB, dan RC
- Distribusi sampling rata‑rata nilai
- Ukuran sampel (n = 30, 1000 kali pengambilan)

# Metode
Analisis Deskriptif, Eksplorasi Data, Distribusi Sampling Rata-rata, dan Selang Kepercayaan 95%.

# Dataset
Dataset berisi nilai akhir mahasiswa mata kuliah Analisis data Statistika (ADS) dari tiga kelas: RA, RB, dan RC. Tiap kolom merepresentasikan nilai akhir masing‑masing kelas.
